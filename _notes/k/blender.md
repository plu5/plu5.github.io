## Raccourcis "Blender"
- navigation : bouton souris milieu + rien/maj/ctrl
- vues orthographiques : alt + pivoter
- transformations : g/s/r/rr
  + + ctrl snap
  + x/y/z verrouiller sur une axe
    - ou bouton souris milieu dans la direction souhaitée
    - + shift pour exclure. par ex. shift + z pour transformer en xy
- ajouter un objet : S-a
- dupliquer un objet : S-d
- **répéter dernière action : S-r**
- déplacer curseur 3d : shift + clic gauche
- toggler panneaux : t/n
- navigation autour du curseur 3d : n → vue → verrouillage de la vue → au curseur 3d
  + utile quand on a bcp d'objets dans la scène
- changer point de pivot : .
- changer orientation : ,
- snap position du curseur/sélection : S-s
- options snap : C-S-tab
- basculer entre modes objet/édition : tab
- **modes pie menu : C-tab**
- **vue pie menu** : \` (grave)
  + utile pour centrer la sélection
- joindre des objets : C-j
- sélectionner faces liées : l
- séparer : p
- mode de sélection sommet/arêt/face : 1/2/3
- mode de rendu : z
- basculer entre modes de rendu filaire/solide : S-z
- ajouter edge loop : C-r
  + nom français pour cet outil : "découper boucle et glisse"
- sélectionner edge/face loop : alt pendant la sélection
- biseauter (bevel) : C-b
  + défiler pour ajouter plus de ségments / arrondir
  + C-v arc
- incruster (inset) : i
  + peut aussi être utilisé pour extruder avec ctrl
- extruder : e
- édition proportionnelle : o
- édition proportionnelle falloff : S-o
- appliquer transformations : C-a
- sélection boîte/pinceau/lasso : w
- (sculpture) brosse draw/claystrips/pinch/inflate/grab/snakehook/fill/crease : v/c/p/i/g/k/S-t/S-c
- (sculpture) chercher brosse : S-space
- (sculpture) basculer entre masque et brosse : m
- (sculpture) **remesh : C-r**
- (sculpture) **résolution de remesh : r**
- (sculpture) **taille : f**
- (sculpture) **force : S-f**
- (sculpture) **masque : m**
  + ctrl pour effacer
- (sculpture) masque cercle/objet/ensemble : S-a
  + [utile pour masquer un ensemble de faces](https://blender.stackexchange.com/questions/274703/how-to-mask-an-entire-faceset-during-sculpting). S-a + ctrl + cliquer l'ensemble
- (sculpture) **édition du masque : a**
- (sculpture) édition des ensembles de faces (face sets) : M-w
- (sculpture) masquage auto : outil → réglages de brosse → avancé
- (sculpture) **stroke method : M-e**
- (sculpture) projection sur ligne : S-0, mais le raccourci ne marche pas pour moi alors je l'ai mis dans les favoris rapides avec toutes les brosses que j'utilise
  + espace pour déplacer la ligne
  + f pour changer le côté qui sera coupé
  + ctrl snapping
  + case à cocher dans la barre latérale "limiter au segment"
- **favoris rapides (quick favourites) : q**
- **cacher : h**
  + avec les ensembles de faces ça affecte l'ensemble survolé avec la souris
- **afficher (révéler) : M-h**
- **cacher/afficher overlays : S-M-z**
- grease pencil annotation : d + bouton souris gauche
  + effacer : d + bouton souris droit
